SME Scripting is the scripting language of StoryModEngine. It connects content created with the editors.

> [!PENDING]
> The SME language specification — syntax, types, built-in functions and execution model — has not been published.

> [!WARNING]
> Until the official specification is available, do not use SME syntax from unofficial sources. Examples on this site will only be added once they are verified against the engine.
