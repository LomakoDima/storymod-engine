## Prerequisites

- Minecraft Java Edition **1.20.1** launches successfully on your machine.
- You have reviewed the [Requirements](/docs/latest/getting-started/requirements).

## Steps

1. Launch Minecraft 1.20.1 once without modifications to confirm the base game works.
2. Download the StoryModEngine release that matches your documentation version from the [Download](/download) page, which links to GitHub Releases.
3. Install the release file using the mod loader setup described below.

> Loader-specific installation steps (loader version, file location and launch profile) will be published with the first release. Do not rely on unofficial instructions.
