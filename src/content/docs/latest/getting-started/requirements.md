## Java

Minecraft Java Edition 1.20.1 requires **Java 17** or newer. The official Minecraft Launcher bundles a suitable runtime. If you use a third-party launcher, check the installed version:

```bash
java -version
```

Expected result: the first line reports version 17 or higher, for example:

```text
openjdk version "17.0.10" 2024-01-16
```
