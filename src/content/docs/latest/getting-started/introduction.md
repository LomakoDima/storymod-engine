StoryModEngine is an in-game content creation engine for **Minecraft Java Edition 1.20.1**. Content is created inside the running game rather than in an external application.

## Components

| Component | Purpose | Documentation status |
| --- | --- | --- |
| Level Editor | Building and arranging levels in-game | Pending |
| NPC Editor | Creating and configuring NPCs | Pending |
| VFX Editor | Creating visual effects | Pending |
| SME Scripting | The engine's scripting language | Pending |

## How this documentation is organized

- **Getting Started** — requirements and installation.
- **Editors** — reference for each in-game editor.
- **SME Scripting** — the scripting language.
- **Guides** — task-oriented walkthroughs.
- **API Reference** — complete technical reference.
- **Troubleshooting** — known problems and how to report issues.

## Documentation conventions

Callouts mark information you should not miss:

> [!NOTE]
> Additional context that helps you understand a topic.

> [!WARNING]
> Actions that can cause data loss or break a setup.

> [!PENDING]
> The section has not been written yet. StoryModEngine documentation never fills these gaps with guessed syntax or behavior — if a section is marked pending, the information is not yet published.
