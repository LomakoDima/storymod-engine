# StoryMod Engine

Create a modern, premium official website for StoryModEngine, an in-game content creation engine for Minecraft Java Edition 1.20.1.

This is a permanent product website, not a temporary v1.0 promotional landing page. It should evolve with the engine and its documentation.

Design direction:

Deep black (#0B0C10), charcoal surfaces, vibrant orange (#FF6A2A), white typography.

Elegant Liquid Glass for floating navigation, buttons and selected UI surfaces: subtle translucency, blur, reflections and depth.

Professional developer-tool aesthetic, sophisticated typography, generous spacing and strong visual hierarchy.

Smooth, purposeful micro-interactions. No generic AI templates, excessive gradients, meaningless decorations or overdone glass effects.

Website structure:

Home: bold hero, product introduction, real engine screenshots, feature highlights.

Features: Level Editor, NPC Editor, VFX Editor, SME Scripting and other tools.

Documentation: clean, searchable, version-aware documentation layout with sidebar navigation, designed for future updates.

Download: version information, installation instructions and GitHub releases.

Changelog: release history and updates.

UX requirements:
Responsive desktop/mobile design, intuitive navigation, excellent readability and consistent components.

Start by building a polished homepage and the shared design system, with navigation and page structure ready for expansion. Use realistic product content without inventing features or statistics.
